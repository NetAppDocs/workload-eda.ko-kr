= Workload Factory for EDA의 개요 대시보드에 대해 알아보십시오
:allow-uri-read: 
:icons: font
:imagesdir: ./media/


[role="lead"]
개요 대시보드는 여러 FSx for ONTAP 파일 시스템에서 EDA 워크로드를 관리하는 IT 관리자에게 중앙 집중식 보기를 제공합니다. 이를 사용하여 클러스터 상태 및 사용량을 신속하게 평가하고, 새 볼륨 또는 작업을 배치할 위치를 결정하고, 볼륨 또는 SVM을 이동할 후보를 식별하고, 용량 또는 처리량을 확장해야 할 시기를 판단할 수 있습니다.



== 개요

개요 대시보드는 구성된 AWS 자격 증명과 연결된 모든 FSx for ONTAP 파일 시스템에 대한 CloudWatch 메트릭을 수집합니다.

다음 내용이 포함됩니다.

* *클러스터 상태*: 상단에 지연 이벤트, SSD 사용률 및 용량 권장 사항, 파일 시스템 전반의 ONTAP EMS 이벤트에 대한 요약 정보가 표시됩니다.
* *클러스터 테이블*: 각 클러스터의 사용량 및 성능 메트릭을 보여주는 상세하고 검색 가능한 테이블로, 필터링, 정렬, 페이지 매김 및 CSV 내보내기를 지원합니다.


다음과 같은 도움이 됩니다.

* 새 볼륨을 배치하고 워크로드의 균형을 재조정합니다
* 용량 또는 처리량 확장 계획
* 대규모 클러스터 상태 모니터링
* 볼륨 배치에 대해 정보에 입각한 결정을 내리십시오
* 용량 한계에 가까워지는 클러스터를 식별합니다




== 대시보드 구성 요소



=== 클러스터 상태

클러스터 상태 정보는 필터링된 파일 시스템 전체의 활동 현황을 보여줍니다. 이 정보는 파일 시스템에 FSx for ONTAP 링크가 하나 이상 연결된 경우에만 표시됩니다.

상태에는 다음 영역이 포함됩니다.

*지연 시간*:: 범위 내 파일 시스템 전체에서 감지된 지연 이벤트 수를 표시합니다. 지연 시간 모니터링을 활성화한 경우에만 지연 시간 정보를 볼 수 있습니다.
*SSD 용량 관리*:: SSD 사용률이 80%를 초과하는 파일 시스템 수와 활성 용량 권장 사항이 있는 파일 시스템 수를 표시합니다. 이를 통해 용량 관리가 필요할 수 있는 파일 시스템을 신속하게 파악할 수 있습니다.
*ONTAP 이벤트*:: 감지된 EMS 이벤트 수를 용량, 가용성 및 보호, 보안 및 기타 범주별로 표시합니다.




=== 클러스터 테이블

클러스터 테이블은 활성 리전 및 AWS 계정 선택 항목을 기준으로 필터링된 각 FSx for ONTAP 파일 시스템에 대한 자세한 보기를 제공합니다. 데이터는 CloudWatch 메트릭에서 수집됩니다.

다음 표를 사용하여 다음을 수행하십시오.

* 용량 한계에 도달하는 파일 시스템 식별(SSD 사용량 열)
* 처리량 수요를 프로비저닝된 처리량 SKU와 비교(처리량 사용량 P99 열)
* 여러 클러스터에 걸쳐 성능 지표를 추적합니다.
* 링크 구성 상태 확인(연결된 링크 열) - 연결 유효성은 매일 검증됩니다
* 대량 매개 변수 업데이트를 위해 여러 클러스터 선택




== SSD 용량 관리

개요 대시보드는 지능형 SSD 용량 관리를 제공합니다.



=== 관리 모드

*자동화*:: Workload Factory는 사전 정의된 임계값과 사용 패턴에 따라 SSD 용량을 자동으로 증가시킵니다. 시스템은 수동 개입 없이 용량 확장을 관리합니다. 자동화된 관리가 선호되는 환경에 이상적입니다.
*권장 사항*:: Workload Factory는 SSD 사용 패턴을 분석하여 용량 증대 권장 사항을 제공합니다. 사용자는 권장 사항을 직접 검토하고 적용할 수 있습니다. 이를 통해 자동화된 분석의 이점을 누리면서도 용량 결정에 대한 완전한 제어권을 확보할 수 있습니다.
*없음*:: 용량 권장 사항이나 자동화된 조치는 수행되지 않습니다. 이는 시스템 지원 없이 수동으로 용량을 관리하려는 경우에 유용합니다.




=== 용량 권장 사항

Workload Factory가 자동화 또는 권장 모드일 때 시스템은 각 FSx for ONTAP 파일 시스템에 대해 용량 권장 알고리즘을 자동으로 실행합니다. 이 알고리즘은 24시간마다 한 번씩 스캔하여 SSD 용량 조정이 권장되는 시점을 식별합니다.

권장 사항이 확인되면:

* Workload Factory 알림 설정에 따라 즉시 알림을 받게 됩니다.
* 권장 사항이 있는 파일 시스템은 클러스터 테이블에서 마지막 SSD 증가 타임스탬프 또는 마지막 SSD 증가 설명 열을 기준으로 필터링하여 확인할 수 있습니다.
* 활성 권장 사항이 있는 파일 시스템의 총 개수가 표시됩니다.


권장 사항에는 제안된 변경 사항과 그 이유가 설명되어 있습니다. 예를 들어, _파일 시스템 SSD 사용 패턴을 기반으로 SSD 크기를 늘리는 것이 좋습니다._



=== SSD 관리 매개 변수

매개 변수는 용량 관리 시스템이 SSD 사용량을 분석하고 처리하는 방식을 제어합니다.

*임계값* (10-90%):: 용량 권장 사항 또는 자동화 작업을 트리거하는 SSD 사용률 백분율입니다. 예를 들어, 임계값이 80%이면 SSD 사용률이 80%에 도달할 때 권장 사항 또는 작업이 수행됩니다. 권장 모드와 자동화 모드 모두에서 사용할 수 있습니다.
*Lookback* (1-200시간):: 과거 SSD 사용 패턴을 분석하는 데 사용되는 기간입니다. 분석 기간이 길수록 용량 결정에 필요한 더 많은 과거 데이터를 확보할 수 있습니다. 자동화 모드에서만 사용 가능합니다.
*앞으로* (1~200시간):: 미래 용량 수요를 예측하는 데 사용되는 기간입니다. 더 긴 기간을 예측하면 미래의 용량 증가를 더 멀리까지 계획할 수 있습니다. Automate 모드에서만 사용 가능합니다.


이러한 파라미터는 각 파일 시스템에 대해 개별적으로 구성하거나 대량 편집을 사용하여 여러 파일 시스템에 일관된 설정을 적용할 수 있습니다.



=== 용량 결정 지점 이해

SSD 사용량 그래프는 용량 권장 사항이 생성되었거나 자동화 작업이 수행된 시점을 나타내는 결정 지점을 표시합니다. 이러한 시각적 지표를 통해 시간 경과에 따른 용량 관리 알고리즘의 동작 방식을 이해할 수 있습니다.

*권장 사항 결정 사항*:: 용량 권장 알고리즘이 추가 SSD 용량이 필요하다고 판단할 때 나타납니다. SSD 용량이 증가하지 않은 경우 이러한 포인트는 30분마다 발생할 수 있습니다. 그래프는 가능한 경우 모든 결정 포인트를 표시하거나, 시간 범위로 인해 개별 포인트가 너무 밀집된 경우 통합하여 표시합니다.
*자동화 의사 결정 지점*:: 자동화 시스템이 SSD 용량을 늘리려고 시도할 때 나타납니다. 이 점들은 자동화 작업이 성공했는지 실패했는지를 나타냅니다.


과거 SSD 사용량 그래프와 함께 의사 결정 지점을 사용하여 다음을 수행하십시오.

* 용량 조정이 얼마나 자주 필요한지 파악하십시오
* 자동화 또는 권장 사항 모드가 워크로드 패턴에 더 적합한지 평가
* 반복적으로 발생하는 용량 제약을 파악합니다
* 성장 추세를 바탕으로 미래 용량 수요를 계획하십시오.
* 자동화 시도 실패 문제 해결
