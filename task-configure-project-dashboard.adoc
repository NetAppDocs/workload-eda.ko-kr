= Workload Factory에서 EDA용 프로젝트 대시보드 구성
:allow-uri-read: 
:icons: font
:imagesdir: ./media/


[role="lead"]
프로젝트, 팀 또는 비용 센터와 같은 비즈니스 구조에 따라 메트릭을 구성하도록 Projects 대시보드에 대한 사용자 지정 필터를 구성합니다. 이를 통해 비용을 정확하게 추적하고, 어떤 리소스가 가장 많은 용량을 소비하는지 파악하며, 리소스 할당 및 예산 계획에 대한 정보에 입각한 의사 결정을 내릴 수 있습니다. 조직 운영 방식에 맞춰 필터를 조정하면 관련 데이터에 신속하게 액세스하여 용량 계획, 비용 추적 및 성능 모니터링의 효율성을 개선할 수 있습니다.



== 시작하기 전에

사용자 지정 필터를 효과적으로 사용하려면 비즈니스 요구 사항에 따라 FSx for ONTAP 볼륨에 AWS 태그를 구성하십시오. 예를 들어 프로젝트, 팀 또는 사업부를 나타내는 태그를 사용할 수 있습니다.



== 사용자 지정 필터 구성


NOTE: 프로젝트 대시보드에 액세스하는 첫 번째 관리자만 사용자 지정 필터를 구성, 추가 또는 삭제할 수 있습니다. 이후 관리자를 포함한 다른 모든 사용자는 필터에 대한 읽기 전용 액세스 권한만 갖습니다.

.이 작업 정보
AWS 태그를 기반으로 최대 5개의 사용자 지정 필터를 구성할 수 있습니다. 각 사용자 지정 필터에는 필터 레이블 이름, AWS 태그 키 이름, 선택 유형(단일 또는 다중 선택)의 세 가지 구성 요소가 필요합니다.

사용자 지정 필터를 구성하지 않으면 기본 필터(파일 시스템, 볼륨 유형 및 시간 범위)가 계속 사용 가능하므로 대시보드를 보고 상호 작용할 수 있습니다.

.단계
. 다음 중 하나를 사용하여 로그인하세요. link:https://docs.netapp.com/us-en/workload-setup-admin/console-experiences.html["콘솔 경험"^].
. 메뉴를 선택하세요 image:workloads-menu-icon.png["햄버거 메뉴 아이콘은 스토리지, EDA, AI, 데이터베이스, VMware 및 관리와 같은 워크로드로 이동하는 데 사용됩니다."] 그런 다음 *EDA*를 선택하십시오.
. *프로젝트*를 선택합니다.
+
대시보드를 아직 구성하지 않았다면 자동으로 구성하라는 메시지가 표시됩니다.

. *+ 필터 추가*를 선택합니다.
. 생성하려는 각 사용자 지정 필터에 대해 세부 정보를 추가합니다.
+
** 필터 레이블 이름(대시보드의 표시 이름)
** AWS 태그 키 이름(리소스에 실제로 사용되는 태그 키)
** 선택 유형(단일 또는 다중 선택)
+

NOTE: 필터는 구성한 순서대로 대시보드에 표시됩니다. 더 쉽게 액세스할 수 있도록 가장 자주 사용하는 필터를 먼저 구성하는 것이 좋습니다.



. *적용*을 선택하세요.
+
변경 사항을 적용하기 전에 해당 필터 옆에 있는 휴지통 아이콘을 선택하여 사용자 지정 필터를 삭제할 수 있습니다.

. 태그나 필터를 적용한 후 변경 사항을 확인하려면 대시보드에서 새로 고침 아이콘을 선택합니다.
. 나중에 대시보드 구성을 수정하려면 *구성*을 선택하세요.


.결과
이러한 태그가 적용되면 Workload Factory는 관련 CloudWatch 지표를 수집하고 표시하기 시작합니다. 대시보드는 조직의 요구 사항에 따라 리소스를 구성하고, 비용을 추적하고, 필터링할 수 있는 동적인 도구가 됩니다.
