= Workload Factory에서 EDA용 프로젝트 대시보드 구성
:allow-uri-read: 
:icons: font
:imagesdir: ./media/


[role="lead"]
프로젝트 대시보드에서 사용자 지정 필터를 설정하여 프로젝트, 팀 또는 비용 센터와 같은 비즈니스 운영 방식에 맞춰 데이터를 정리할 수 있습니다. 이를 통해 비용을 명확하게 파악하고, 어떤 리소스가 가장 많은 스토리지 용량을 사용하는지 알아내어 예산 및 인력 배치에 대한 더 나은 의사 결정을 내릴 수 있습니다. 필터가 조직 구조와 일치하면 필요한 데이터를 신속하게 찾고 스토리지 용량, 비용 및 성과를 더욱 효율적으로 관리할 수 있습니다.



== 시작하기 전에

사용자 지정 필터를 사용하려면 프로젝트, 팀 또는 사업부 태그와 같이 필요에 따라 FSx for ONTAP 볼륨에 AWS 태그를 추가하세요.



== 사용자 지정 필터 구성


NOTE: 프로젝트 대시보드를 처음 여는 관리자만 사용자 지정 필터를 생성, 변경 또는 삭제할 수 있습니다. 다른 관리자를 포함한 모든 사용자는 필터를 보기만 할 수 있습니다.

.이 작업 정보
AWS 태그를 사용하여 최대 5개의 사용자 지정 필터를 구성할 수 있습니다. 각 필터에는 필터 레이블, AWS 태그 키 및 선택 유형(단일 또는 복수)이 필요합니다.

사용자 지정 필터를 구성하지 않으면 기본 필터(파일 시스템, 볼륨 유형 및 시간 범위)가 계속 사용 가능하므로 대시보드를 계속 보고 사용할 수 있습니다.

.단계
. 다음 중 하나를 사용하여 로그인하세요. link:https://docs.netapp.com/us-en/workload-setup-admin/console-experiences.html["콘솔 경험"^].
. 메뉴를 선택하세요 image:workloads-menu-icon.png["햄버거 메뉴 아이콘은 스토리지, EDA, AI, 데이터베이스, VMware 및 관리와 같은 워크로드로 이동하는 데 사용됩니다."] 그런 다음 *EDA*를 선택하십시오.
. *프로젝트*를 선택합니다.
+
대시보드를 아직 구성하지 않았다면 자동으로 구성하라는 메시지가 표시됩니다.

. *+ 필터 추가*를 선택합니다.
. 생성하려는 각 사용자 지정 필터에 대해 세부 정보를 추가합니다.
+
** 필터 레이블 이름(대시보드의 표시 이름)
** AWS 태그 키 이름(리소스에 실제로 사용되는 태그 키)
** 선택 유형(단일 또는 다중 선택)
+

NOTE: 필터는 설정한 순서대로 대시보드에 표시됩니다. 가장 자주 사용하는 필터를 맨 위에 배치하면 더 쉽게 액세스할 수 있습니다.



. *적용*을 선택하세요.
+
변경 사항을 적용하기 전에 해당 필터 옆에 있는 휴지통 아이콘을 선택하여 사용자 지정 필터를 삭제할 수 있습니다.

. 태그나 필터를 적용한 후 변경 사항을 확인하려면 대시보드에서 새로 고침 아이콘을 선택합니다.
. 나중에 대시보드 구성을 수정하려면 *구성*을 선택하세요.


.결과
이러한 태그를 적용하면 Workload Factory는 관련 CloudWatch 지표를 수집하여 표시하기 시작합니다. 그러면 대시보드를 통해 리소스를 구성하고, 비용을 추적하고, 필요에 따라 항목을 필터링할 수 있습니다.
