= Workload Factory for EDA의 프로젝트 대시보드에 대해 알아보십시오
:allow-uri-read: 
:icons: font
:imagesdir: ./media/


[role="lead"]
프로젝트 대시보드는 IT 관리자와 프로젝트 관리자가 FSx for ONTAP 파일 시스템 및 볼륨 전반의 프로젝트 사용량을 관찰하고 분석하는 데 도움을 줍니다. 스토리지 사용 패턴에 대한 가시성을 제공하여 리소스 집약적인 프로젝트를 식별하고, 비용을 추적하고, 용량 또는 성능 문제가 EDA 시뮬레이션에 영향을 미치기 전에 스토리지 할당을 최적화할 수 있도록 지원합니다.



== 프로젝트 대시보드 작동 방식

프로젝트 대시보드는 AWS 자격 증명과 연결된 모든 FSx for ONTAP 볼륨에 대한 CloudWatch 메트릭을 수집합니다. AWS 태그를 기반으로 최대 5개의 사용자 지정 필터를 생성하여 프로젝트, 팀 또는 애플리케이션과 같은 특정 비즈니스 요구 사항에 따라 데이터를 구성하고 필터링할 수 있습니다.

대시보드는 다음과 같은 도움을 줍니다.

* 용량을 계획하고 비용을 평가하세요
* 리소스 할당에 대해 데이터 기반 의사 결정 수행
* 리소스 집약적인 프로젝트 식별
* 프로젝트 또는 팀 전체의 비용을 정확하게 추적하십시오
* 문제가 발생하기 전에 스토리지 할당을 최적화하세요.


사전 예방적 지연 시간 성능 모니터링에 대해서는 link:learn-latency-monitoring.html["지연 시간 모니터링에 대해 알아보십시오"]을 참조하십시오.



=== CloudWatch 메트릭 수집됨

대시보드는 다음과 같은 CloudWatch 지표를 수집하여 표시합니다.

* *프로비저닝된 용량*: 프로비저닝된 스토리지 용량을 나타내는 볼륨 수준 메트릭입니다.
* *사용 용량*: 사용된 스토리지를 나타내는 볼륨 수준 지표입니다.
* *평균/최대 처리량*: 지정된 기간 동안 DataReadBytes와 DataWriteBytes의 합계의 평균 또는 최대값으로 계산됩니다.
* *평균/최대 IOPS*: 지정된 기간 동안 DataReadOperations, DataWriteOperations 및 MetadataOperations의 합계에 대한 평균 또는 최대값으로 계산됩니다.




== 사용자 지정 필터

사용자 지정 필터를 사용하면 조직 운영 방식에 따라 대시보드 데이터를 구성할 수 있습니다. 프로젝트 구조, 팀 또는 비용 센터에 맞춰 필터를 설정하면 관련 없는 정보를 탐색하지 않고 필요한 특정 데이터에 빠르게 접근할 수 있습니다. 이를 통해 용량 계획, 비용 추적 및 성능 모니터링을 더욱 효율적으로 수행할 수 있습니다.

AWS 태그를 기반으로 최대 5개의 사용자 지정 필터를 구성할 수 있습니다. 각 사용자 지정 필터에는 다음 구성 요소가 필요합니다.

* *필터 레이블 이름*: 대시보드에 표시되는 표시 이름
* *AWS 태그 키 이름*: 리소스에 사용되는 실제 AWS 태그 키
* *선택 유형*: 단일 선택 또는 다중 선택


사용자 지정 필터를 구성하지 않으면 기본 필터(파일 시스템, 볼륨 유형 및 시간 범위)가 계속 사용 가능하므로 대시보드를 보고 상호 작용할 수 있습니다.



=== AWS 태그

AWS 태그는 AWS 리소스에 대한 메타데이터입니다. 태그를 사용하면 프로젝트, 애플리케이션 또는 사업부 등 다양한 방식으로 AWS 리소스를 분류할 수 있습니다.

사용자 지정 필터를 효과적으로 사용하려면 비즈니스 요구 사항에 따라 FSx for ONTAP 볼륨에 AWS 태그를 구성하십시오. 예를 들어 프로젝트, 팀 또는 사업부를 나타내는 태그를 사용할 수 있습니다.

태그에 대한 자세한 내용은 https://docs.aws.amazon.com/whitepapers/latest/tagging-best-practices/what-are-tags.html["태그란 무엇인가요?"^] 및 https://docs.aws.amazon.com/resourcegroupstagging/latest/APIReference/overview.html["AWS 리소스 그룹 태깅 API 참조"^]을 참조하세요.



== 볼륨 세부 정보

대시보드는 다양한 수준의 세부 정보로 스토리지 지표를 분석할 수 있도록 보기 모드를 제공합니다.



=== 전체 보기

전체 보기(기본값)는 선택한 필터와 일치하는 모든 볼륨의 집계된 메트릭을 표시합니다. 이 보기는 전체 스토리지 성능에 대한 높은 수준의 개요를 제공하며, 결합된 용량, IOPS 및 처리량 메트릭을 보여줍니다.

이 보기를 사용하여 다음을 수행하십시오.

* 전반적인 추세 파악
* 향후 용량 요구 사항 계획
* 프로젝트 또는 팀 전체의 총 리소스 사용량에 대한 보고서




=== 볼륨 보기

볼륨 보기에서는 시간 경과에 따른 개별 볼륨 성능을 표시하며, 각 메트릭별로 상위 10개 볼륨을 보여줍니다. 이 보기를 통해 리소스 사용량을 주도하는 특정 볼륨을 파악하고 선택한 기간 동안의 동작을 관찰할 수 있습니다.

이 보기를 사용하여 다음을 수행하십시오.

* 성능 병목 현상 찾기
* 규모 조정이 필요할 수 있는 볼륨을 파악합니다
* 가장 많은 리소스를 소비하는 특정 프로젝트 또는 워크로드를 정확히 파악하십시오




==== 표시된 볼륨 메트릭

개별 볼륨을 볼 때 대시보드에는 각 지표별로 전체 볼륨 중 상위 10개 볼륨이 표시됩니다.

* *볼륨 사용 용량*: 현재 사용 용량이 가장 높은 볼륨을 보여줍니다.
* *IOPS*: 선택한 기간 동안 평균 IOPS가 가장 높은 볼륨을 표시합니다.
* *처리량*: 선택한 기간 동안 평균 처리량이 가장 높은 볼륨을 보여줍니다.



NOTE: 대시보드에는 각 지표별로 상위 10개 볼륨만 표시됩니다. 볼륨이 10개를 초과하는 경우 일부 볼륨은 상세 보기에서 표시되지 않을 수 있습니다.

여러 메트릭에서 동일한 볼륨이 나타날 경우, 대시보드는 범례에 일관된 색상 코딩을 사용하여 다양한 메트릭에서 특정 볼륨을 쉽게 추적할 수 있도록 합니다.



==== 대화형 볼륨 데이터

대화형 호버 데이터는 특정 시점의 정확한 메트릭을 제공하여 성능 변화와 특정 이벤트 또는 기간 사이의 상관관계를 파악하는 데 도움을 줍니다. 이러한 상세 정보는 성능 문제 해결, 최적화 노력 검증 또는 이해관계자에게 리소스 사용 패턴을 설명하는 데 유용합니다.

그래프에서 볼륨 라인 위에 마우스를 올리면 다음을 볼 수 있습니다.

* *볼륨 사용 용량*: 볼륨 이름, 해당 시점의 사용 용량 및 할당 용량
* *IOPS*: 볼륨 이름, 시간 범위의 평균 IOPS 및 시간 범위의 최대 IOPS
* *처리량*: 볼륨 이름, 해당 기간 동안의 평균 처리량 및 해당 기간 동안의 최대 처리량
