= Workload Factory for EDA의 프로젝트 대시보드에 대해 알아보십시오
:allow-uri-read: 
:icons: font
:imagesdir: ./media/


[role="lead"]
프로젝트 대시보드를 통해 IT 관리자와 프로젝트 관리자는 FSx for ONTAP 파일 시스템 및 볼륨에서 프로젝트가 스토리지를 어떻게 사용하는지 확인할 수 있습니다. 스토리지 사용 패턴을 보여주므로 가장 많은 리소스를 사용하는 프로젝트를 파악하고, 비용을 추적하고, 용량이나 성능 문제가 EDA 시뮬레이션에 영향을 미치기 전에 스토리지를 조정할 수 있습니다.



== 프로젝트 대시보드 작동 방식

프로젝트 대시보드에는 AWS 자격 증명에 연결된 모든 FSx for ONTAP 볼륨에 대한 CloudWatch 지표가 표시됩니다. AWS 태그를 사용하여 최대 5개의 필터를 생성하고 프로젝트, 팀, 애플리케이션 또는 기타 범주별로 데이터를 정리하고 볼 수 있습니다.

대시보드는 다음과 같은 도움을 줍니다.

* 용량을 계획하고 비용을 파악합니다.
* 데이터를 활용하여 리소스 할당 방법을 결정하십시오
* 많은 리소스를 사용하는 프로젝트 파악
* 프로젝트 또는 팀별 비용 추적
* 문제가 발생하기 전에 스토리지를 조정하십시오.


사전 예방적 지연 시간 성능 모니터링에 대해서는 link:learn-latency-monitoring.html["지연 시간 모니터링에 대해 알아보십시오"]을 참조하십시오.



=== CloudWatch 메트릭 수집됨

대시보드는 다음과 같은 CloudWatch 지표를 수집하여 표시합니다.

* *프로비저닝된 용량*: 프로비저닝된 스토리지 용량을 나타내는 볼륨 수준 메트릭입니다.
* *사용 용량*: 사용된 스토리지를 나타내는 볼륨 수준 지표입니다.
* *평균/최대 처리량*: 지정된 기간 동안 DataReadBytes와 DataWriteBytes의 합계의 평균 또는 최대값으로 계산됩니다.
* *평균/최대 IOPS*: 지정된 기간 동안 DataReadOperations, DataWriteOperations 및 MetadataOperations의 합계에 대한 평균 또는 최대값으로 계산됩니다.




== 사용자 지정 필터

사용자 지정 필터를 사용하면 조직의 업무 방식에 맞춰 대시보드 데이터를 구성할 수 있습니다. 프로젝트, 팀 또는 비용 센터별로 필터를 설정하면 관련 없는 정보를 일일이 살펴볼 필요 없이 필요한 데이터를 빠르게 찾을 수 있습니다. 이를 통해 용량 계획, 비용 추적 및 성능 모니터링이 더욱 간편해집니다.

AWS 태그를 기반으로 최대 5개의 사용자 지정 필터를 구성할 수 있습니다.

* *필터 레이블 이름*: 대시보드에 표시되는 표시 이름
* *AWS 태그 키 이름*: 리소스에 사용되는 실제 AWS 태그 키
* *선택 유형*: 단일 선택 또는 다중 선택


사용자 지정 필터를 구성하지 않으면 기본 필터(파일 시스템, 볼륨 유형 및 시간 범위)가 계속 사용 가능하므로 대시보드를 보고 사용할 수 있습니다.



=== AWS 태그

AWS 태그는 AWS 리소스에 대한 메타데이터입니다. 태그를 사용하면 프로젝트, 애플리케이션 또는 사업부 등 다양한 방식으로 AWS 리소스를 분류할 수 있습니다.

사용자 지정 필터를 사용하려면 프로젝트, 팀 또는 사업부 태그와 같이 필요에 맞는 AWS 태그를 FSx for ONTAP 볼륨에 추가하십시오.

태그에 대한 자세한 내용은 https://docs.aws.amazon.com/whitepapers/latest/tagging-best-practices/what-are-tags.html["태그란 무엇인가요?"^] 및 https://docs.aws.amazon.com/resourcegroupstagging/latest/APIReference/overview.html["AWS 리소스 그룹 태깅 API 참조"^]을 참조하세요.



== 볼륨 세부 정보

대시보드는 다양한 수준의 세부 정보로 스토리지 지표를 분석할 수 있도록 보기 모드를 제공합니다.



=== 전체 보기

전체 보기(기본값)는 선택한 필터와 일치하는 모든 볼륨의 통합 메트릭을 보여줍니다. 이를 통해 총 용량, IOPS 및 처리량을 포함한 전반적인 스토리지 성능을 빠르게 파악할 수 있습니다.

이 보기를 사용하여 다음을 수행하십시오.

* 전반적인 추세 파악
* 향후 용량 요구 사항 계획
* 프로젝트 또는 팀 전체의 총 리소스 사용량에 대한 보고서




=== 볼륨 보기

볼륨 보기에서는 개별 볼륨의 시간 경과에 따른 성능을 확인할 수 있습니다. 각 메트릭별로 상위 10개 볼륨을 표시합니다. 어떤 볼륨이 가장 많은 리소스를 사용하는지, 그리고 선택한 기간 동안 어떻게 작동하는지 파악하는 데 도움이 됩니다.

이 보기를 사용하여 다음을 수행하십시오.

* 성능 저하의 원인 찾기
+
** 크기 조정이 필요할 수 있는 스토리지 볼륨 식별
** 어떤 프로젝트 또는 워크로드가 가장 많은 리소스를 사용하고 있는지 확인합니다.






==== 표시된 볼륨 메트릭

개별 볼륨을 볼 때 대시보드에는 각 지표별로 전체 볼륨 중 상위 10개 볼륨이 표시됩니다.

* *볼륨 사용 용량*: 현재 사용 용량이 가장 높은 볼륨을 보여줍니다.
* *IOPS*: 선택한 기간 동안 평균 IOPS가 가장 높은 볼륨을 표시합니다.
* *처리량*: 선택한 기간 동안 평균 처리량이 가장 높은 볼륨을 보여줍니다.



NOTE: 대시보드에는 각 지표별로 상위 10개 볼륨만 표시됩니다. 볼륨이 10개를 초과하는 경우 일부 볼륨은 상세 보기에서 표시되지 않을 수 있습니다.

여러 지표에서 동일한 볼륨이 나타날 경우, 대시보드의 범례에는 동일한 색상이 사용되어 다양한 지표에서 해당 볼륨을 쉽게 추적할 수 있습니다.



==== 대화형 볼륨 데이터

차트에 마우스를 올리면 특정 시점의 정확한 값을 확인할 수 있습니다. 이를 통해 성능 변화를 특정 이벤트 또는 기간과 연결할 수 있습니다. 상세 데이터를 활용하면 성능 문제를 발견하고, 최적화 작업이 성공적이었는지 확인하고, 리소스 사용 현황을 다른 사람에게 설명할 수 있습니다.

그래프에서 볼륨 라인 위에 마우스를 올리면 다음을 볼 수 있습니다.

* *볼륨 사용 용량*: 볼륨 이름, 해당 시점의 사용 용량 및 할당 용량
* *IOPS*: 볼륨 이름, 시간 범위의 평균 IOPS 및 시간 범위의 최대 IOPS
* *처리량*: 볼륨 이름, 해당 기간 동안의 평균 처리량 및 해당 기간 동안의 최대 처리량
